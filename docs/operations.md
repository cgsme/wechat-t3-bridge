## 凭据与消息处理

扫码返回的微信用户 ID 是唯一允许发送任务的人。没有这个 ID 时，桥接不会启用。群消息和其他用户消息被忽略。凭据只保存在受 Windows ACL 限制的本机目录，运行日志不记录凭据或消息正文。

模型、项目及补充问题控制连接本机 T3 的 MCP 接口，只接受回环地址，拒绝重定向。读取操作通过 CLI 签发两分钟的只读凭据；写操作使用 CLI 生成的一次性配对凭据完成 T3 自身的 PKCE 授权。每次控制调用结束后关闭会话并撤销凭据，令牌不写入配置或日志。项目查询使用项目列表和详情接口；不更改线程运行权限，也不自动批准权限请求。

收件箱与微信游标一起持久化，并按消息 ID 去重。跨会话并发不设数量上限，同一会话保持顺序。切换、状态和帮助命令不必等待长任务完成；消息分派时固定目标会话。`/new` 在新线程创建并选中后释放控制队列，首次任务在后台等待。不同会话的回复可能按完成顺序返回；单条回复发送失败不会阻塞其他会话。重启时正在执行的任务不会自动重跑，以免重复操作。发送失败会重试回复，沿用相同的客户端消息 ID；微信服务端没有承诺严格的发送幂等性。

每条 `/new` 的启动通知和最终结果都显示所属线程的紧凑标识和原始提问；启动通知单独持久化发送进度，发送失败时不阻塞其他线程。后台完成旧任务时不会改变当前选中线程。

桥接在回复开头显示 `#序号 线程名（短ID）`，不显示完整线程 ID 和地址。短 ID 默认取至少 4 个字符，遇到已知线程前缀冲突时自动加长；省略 `mcp:` 传输前缀，纯数字前缀会延长到不与线程编号混淆。短 ID 可直接用于 `/switch` 和 `/to`，也可使用 `#2` 这样的编号。完整 ID 仍用于内部路由。新线程追加到现有编号末尾，各项目分别保存编号；刷新 `/threads` 时，以新显示的编号为准。

每条回复在线程标识下方显示 `指令：原始提问摘要`，摘要保留前 160 个字符，长问题加省略号。并发任务、失败回复、新线程回执和长回复的每个分段都保留对应提问。补充问题收集与任务继续执行后仍保留最初的任务提问。切换线程后，旧任务仍使用自己的线程名、短 ID 和问题；创建线程前的接收通知标注发起请求时的线程。

`/new` 的创建回执、成功确认和任务结果分开发送并保存各自进度。创建调用未返回有效结果时，明确提示“尚未确认”，请先用 `/threads` 或在 T3 中核对，避免重复创建；已收到新线程 ID 但后续校验失败时仍返回该 ID。已确认创建后，即使结果查询失败或桥接重启，也会保留 ID 和已知链接，不把任务结果未知误报为创建失败，不自动重建线程或重跑任务。

任务正文进入选中的 T3 上下文；`/new` 的内容作为新线程的首次任务。桥接通过子进程标准输入传递用户正文，不拼接 shell 命令。线程选择限于当前选中项目的可用顶层线程，`home` 显式指向最初绑定的线程；已归档线程和子 agent 线程不作为切换目标。项目查询通过只读 MCP 接口执行，按页读取并过滤已删除项目。

## 更新运行中的桥接

从微信发起桥接自身的更新时，`upgrade.ps1` 可以先暂存代码，等指定消息已回复、收件箱为空时再备份旧版、重启和检查微信轮询。它核对进程路径、创建时间与锁文件，只重启对应的桥接进程，保留微信凭据和消息状态。

升级替换文件前会写入 `data\supervisor-pause.json`，守护在升级或回滚结束前暂停拉起桥接；该记录只有所有者进程仍在运行时才生效。

## 启动与自动恢复

当前用户登录 Windows 后，守护检查 T3 连接。桌面端未运行时自动启动，连接失败按 5、10、20、30 秒的间隔持续重试；已有桥接会被接管，桥接退出后重新启动。它只管理程序进程，不重发消息或重新执行任务。用户未登录、系统休眠或网络不可用时不保证微信即时响应；绑定失效需要重新扫码。

`data\supervisor-status.json` 的 `phase` 为 `waiting_for_t3` 时表示等待 T3，`starting_bridge` 为启动桥接，`running` 为桥接进程已运行，`maintenance` 为升级暂停，`retrying` 为进程操作失败后等待重试。`data\status.json` 继续记录微信连接；守护拉起桥接的输出保存在 `data\supervisor-bridge.log`。

## 停用

删除 Windows 启动文件夹内的 `WeChatT3Bridge.vbs` 可以关闭下次登录时的自动启动。要立即停用，先结束 `data\supervisor.lock` 指向的守护，再结束 `data\bridge.lock` 指向的桥接；结束前分别确认命令行指向本安装的 `supervisor.mjs`、`bridge.mjs`，否则守护会自动拉起桥接。微信中解除 ClawBot 绑定可撤销微信端连接。
